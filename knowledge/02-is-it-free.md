# Is it free to use?

Yes. Katie Travel is currently a free prototype. There are no subscriptions, and we never ask for payment details.

To keep the service running smoothly for everyone, there are some daily limits:
- Each account can send up to 50 messages a day to Katie.
- Place searches across the whole service are capped each day. If the cap is reached, Katie will tell you she can't look up new places until tomorrow.

Limits reset at midnight UTC.

If this changes in future, for example if paid features are added, we'll say so clearly before anything changes for you.
